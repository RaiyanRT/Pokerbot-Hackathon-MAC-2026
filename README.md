# Pokerbot-Hackathon-MAC-2026

##Introduction

##Methodology
This bot was developed using an evolutionary training loop with AI-generated variants.

**Loop**
1. Generation 0: Five bots are written independently from different AI
2. Evaluate: All bots play against eachother using the 'macpoker' engine with duplicate deals (everybot has to play the same hand) across thousands of combinations to account for luck and multiple scenarios
3. Select: THe best variant is crowned the champion, and four new variants are generated by giving the models the code of the champion's code and results
4. Repeat: Will continue cycling through this loop 5-8 times

**Considerations**
Selecting only against the current generation can cause counter strategies to cycle (kind of like rock paper scissors). To prevent this every candidate is also evaluated against:
- Fixed Baselines: The build-in house bots, which provide a constant measurement of progress
- Previous Champions: Every previous champion will also play against any potential candidate to measure whether they can compete with past strategies
